Research · SecurityPrivFed ↗

PrivFed-TCN: private intrusion detection for IoT

A compact temporal convolutional network with multi-head attention, trained across devices with federated learning. Updates are protected by DP-SGD with Rényi-DP accounting, SecAgg+ secure aggregation and Krum filtering against poisoned clients.

On CIC-IoT-2023 (14 classes) at the same privacy budget (ε ≤ 1.0), it beats a 2-layer FL-LSTM while sending far less data each round.

Enterprise · Document AIVagent ↗

Vagent: RFP requirements to a priced compliance sheet

Takes a dense tender PDF, finds the technical specification pages, parses nested requirement tables and recommends exact hardware models for each line.

Every Fortinet answer links to the chapter and page of the FortiOS admin guide that proves it, so the output works as audit evidence.

  3. Parse the tablesGemini turns multi-column, nested tables into a compliance JSON schema.
  4. Match the catalogsRAG plus rules pick firewalls, switches, UPS and cooling models.
  5. Cite and exportEmbeds page-level citations and writes a styled Excel workbook.

AutoCAD MCP: draw with Claude

An MCP server that connects a live AutoCAD session on a Windows PC to Claude on the web. Claude can create, inspect and edit drawings through 149 tools.

It runs on two backends: the AutoCAD COM API for live drawings, and ezdxf for working with DXF files directly.

Voice · Device automationVAS ↗

V.A.S.: a voice assistant that runs my phone

Spoken commands go to Llama 3.3 70B on Groq, which returns a structured intent. The assistant then unlocks the phone, opens apps and sends WhatsApp or SMS messages over ADB, with no root.

Messages are sent by reading the live UI tree, so it taps the real Send button and checks the message went out instead of relying on fixed screen positions.

CrisisSim: LLM agents after an earthquake

A simulation where medic, truck and drone agents coordinate a rescue. It compares three LLM reasoning strategies under real constraints: battery limits, rubble, full hospitals and aftershocks that start new fires.
